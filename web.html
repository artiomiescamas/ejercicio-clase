El Cuerpo Humano

Sistema Digestivo

El sistema digestivo es el encargado de procesar los alimentos y extraer los nutrientes necesarios para el cuerpo.

Sistema Circulatorio

El sistema circulatorio transporta sangre, oxígeno y nutrientes a todas las partes del cuerpo.

Sistema Nervioso

El sistema nervioso controla y coordina las funciones del cuerpo a través de señales eléctricas.
